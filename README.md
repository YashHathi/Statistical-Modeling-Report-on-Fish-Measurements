# Statistical-Modeling-Report-on-Fish-Measurements

*An analysis of 159 different fish and their various measurements*

This project was my final project for my STAT 425 (Statistical Modeling I) course. This project is a R Markdown data analysis report which determines which are the best measurements in determining a fishes weight. 

## Core tenants of this project include:
- EDA
- Data Visualization
- Linear Regression
- Model Transformation
- Feature Selection
- Regression Diagnostics
- ANOVA

## Data Set
The dataset used for this project is the Fish.csv dataset. Here is a kaggle page with more info. 
https://www.kaggle.com/datasets/aryansingh2001/fish-csv

## Tools for this project include:
- R
- R Markdown
- Leaps Package
